🛠 真·Agent 架构（不是写死流水线）

  1. LLM 自主规划：评分前 LLM 先审视热点、制定策略（不是写死的）
  2. LLM 自主选择：LLM 自己决定选哪条选题（不硬取 top1）
  3. LLM 自检+重试：生成后 LLM 自评质量，不通过则带反馈重新生成（最多 2 次）
  4. 每个评分/拆解/生成都是 真实 LLM 响应，工作流显示真实耗时/token/推理
  5. API Key 存浏览器 localStorage，不上传任何服务器
  6. 不配代理也能用，Agent 1 用缓存 + 仍是真实 LLM 调用

📡 数据抓取（CORS 代理）

浏览器直连微博/头条/B站会被 CORS 拦。两种方式：
① 本地代理：跑 node proxy-example.js，填 http://localhost:8088/（30 秒搞定）
② 公共代理：留空自动试 corsproxy.io / allorigins 等（不一定稳）
③ Cloudflare Worker：用 proxy-example.js 改 5 行就能部署
